CORS Proxy Setup (one-time, ~3 min)

FRED and Yahoo Finance don't send CORS headers, so a static site can't reach them directly. The free public proxies (corsproxy.io, allorigins) are now blocked or paywalled in 2026. Deploy a personal Cloudflare Worker — free, no card required, 100k requests/day.
  1. Sign up at dash.cloudflare.com/sign-up (free).
  2. Go to Workers & Pages → Create application → Create Worker.
  3. Name it (e.g. capital-proxy) → Deploy.
  4. Click Edit code, replace everything with the snippet below, click Deploy.
  5. Copy your Worker URL (e.g. https://capital-proxy.YOURNAME.workers.dev).
  6. Paste it into CORS Proxy URL above and click Save, then Refresh All Data.

Reset

This tool aggregates macro signals for personal allocation guidance only. No signal is reliable in isolation. The framework acknowledges genuine contradictions between liquidity models (Pal stock vs Howell flow). All regime signals are probabilistic, not deterministic. Past correlation between liquidity and asset prices is time-varying and regime-dependent. This is a decision-support tool, not financial advice.
